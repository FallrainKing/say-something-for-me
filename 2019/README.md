## 补充说明

这些事情都是 2019 年发生，距今八年有余。我知道很多人其实并不关心真相怎么样，只是为了看乐子，所以我也不多说评论，直接把原来的所有截图放出来，不做过多的解释。并且我这里还有各种各样的骚扰证据，包括电话轰炸、发动网友打电话、五千多封侮辱谩骂的邮件，因为涉及到隐私，需要先脱敏。但是如果……

## 几个 QA

**Q1：博主自己本身是不是也有问题？**

我并不认为自己没问题，也有人提醒过我做事有欠缺，也有和我关系不和之人。但是跟这厮有什么关系呢？

**Q2：就任凭这厮这么折腾吗？**

据了解，这厮残疾常年卧床不出。19 年找到其家里后，其消停了一段时间。但是后来，其家里也没办法管。并且其家庭在本村也是毫不讲理之家。24 年其发动网友骚扰，报警，警察也是调解为主，与其交涉时声泪俱下，警察也不知怎么办。这些年我一直以来的原则是，惹不起躲得起，更换 QQ、手机、微信等号，不回复，看不见。

**Q3：为什么这厮能了解这么多？**

感觉我朋友圈中有人被蛊惑而递刀子，但是我这的察觉不出来是谁。这一次就有人把我的微信、抖音等内容泄漏，甚至还有我在校时候的照片（真想不清楚怎么找到的，我多年前发的且朋友圈三天可见）。我希望有人能给我说一下，并不会怪罪。但是如果是故意的话，恐怕这厮也会出卖你。

**Q4：对生活影响大吗？**

如果只是骚扰我，这么多年过来了，并且我都会主动跟朋友们讲这个事情。但是这次这厮真的玩大了，连续多少天，不说什么内容，一味地发，已经严重影响到我了。感谢我的朋友们看到主动来联系我，并且点击举报。
